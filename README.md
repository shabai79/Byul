# ✦ Byul — 세계 어디서든, 잃어버린 물건 찾기

전 세계 어느 장소에서 물건을 잃어버렸을 때, **그 지점에 물건 정보·사진·이야기를 남기면**
그곳에 살거나 **곧 여행 갈 사람**이 글을 보고 찾아주는 중개 서비스입니다.
연락은 **서비스 안에서만** 가능하고, 찾아주면 **사례금에 수수료**가 붙습니다.

## 실행

```bash
npm install
npm start        # http://localhost:3000
npm test         # 전체 흐름 자동 테스트
```

## MVP 기능

| 기능 | 설명 |
|---|---|
| 🗺️ 지도에 분실물 등록 | 장소 검색 또는 지도 클릭으로 위치 지정, 사진 4장, 특징, 이야기, 사례금 |
| 🔎 탐색 | 지도 마커 + 목록, 검색어·분류 필터 |
| ✈️ 여행 매칭 | 여행지·날짜·반경을 등록하면 주변 분실물을 자동으로 보여줌 (핵심 차별점) |
| 💬 서비스 내 메시지 | 전화번호·이메일·URL·메신저 ID 자동 가림 → 직거래(수수료 회피) 방지 |
| 💰 에스크로 거래 | 도움 수락 → 분실자 결제·예치 → 발송/전달 → 수령 확인 후 정산 |
| 🌐 다국어 | 한국어·English·日本語·中文. 브라우저 언어 자동 감지 + 상단 메뉴에서 변경, 통화·날짜도 언어별 표기 |
| 🔤 글 번역 | 다른 언어로 쓰인 분실물 글과 받은 메시지에 "번역 보기" 버튼 (현재는 Google 번역 새 창) |
| 🧾 수수료 | 기본 사례금의 10% (`FEE_RATE` 환경변수로 변경) |

## 구조

- `server.js` — Express API (인증, 게시글, 여행, 메시지, 거래)
- `public/` — 순수 HTML/JS 프론트엔드, 지도는 Leaflet + OpenStreetMap
- `data/db.json` — MVP용 파일 저장소 (실서비스 전환 시 DB로 교체)

## 다국어 구조

- 화면 문구: `public/i18n.js` 한 파일에 언어별 사전. **새 언어 추가 = `LANGS`에 이름 추가 + `MESSAGES`에 같은 키로 번역 추가.**
  빠진 키는 영어로 대체되고, `npm test`가 모든 언어의 키가 같은지 검사합니다.
- 서버 오류 문구: `lib/messages.js` (요청의 `X-Lang` / `Accept-Language` 헤더로 언어 결정)
- 분류·상태·가려진 연락처는 언어 중립 키(`jewelry`, `[[contact]]` 등)로 저장하고 화면에서 번역
- 글마다 작성 언어(`lang`)를 저장해서, 읽는 사람 언어와 다르면 번역 버튼을 크게 표시

## 실서비스로 가기 위해 필요한 것

1. **결제·정산**: 현재 결제는 데모. 토스페이먼츠 지급대행 / Stripe Connect 같은 *마켓플레이스 정산* 상품 필요.
   남의 돈을 맡아두는 구조라 국내는 **PG사 에스크로/지급대행**을 써야 직접 전자금융업 등록을 피할 수 있음.
2. **법률 검토**: 한국 *유실물법*상 습득자는 경찰·시설에 신고 의무가 있고, 보상금은 물건 가치의 5~20% 범위.
   서비스는 “직접 습득”보다 **“현지 분실물센터 문의·수령 대행 + 배송”**으로 포지셔닝하는 것이 안전.
   해외 국가별 규정, 여권 등 신분증(대사관 처리 대상), 통관 금지 품목도 확인 필요.
3. **신뢰·안전**: 본인인증, 사기 방지(가짜 “찾았어요”), 사진 인증, 리뷰/평점, 신고 기능, 개인 위치 노출 최소화.
4. **인프라**: PostgreSQL + PostGIS(위치 검색), S3 이미지 저장, 푸시 알림(여행지 근처 분실물 알림), 다국어.
5. **번역 고도화**: Google 번역 새 창 대신 DeepL·Papago·Claude API로 화면 안에서 바로 번역 (API 키 필요).
6. **앱**: 웹을 먼저 검증한 뒤 React Native/Flutter 또는 PWA로 모바일 앱화.

- 공항·호텔·관광지 분실물센터와 B2B 제휴 (보관 중인 물건을 Byul에 등록)
